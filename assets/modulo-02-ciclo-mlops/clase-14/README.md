# Recursos visuales — Clase 14

`flujo-streamlit-fastapi-mlflow.svg` es un recurso propio del curso que muestra
el recorrido mínimo de una solicitud y una respuesta entre la persona,
Streamlit, FastAPI y el MLflow Model seleccionado. Se mantiene deliberadamente
simple para distinguir responsabilidades sin anticipar contenedores o redes.

El recurso forma parte del material propio del repositorio y usa su licencia
MIT.
