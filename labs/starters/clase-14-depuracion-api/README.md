# Starter — Depuración de una API

Esta carpeta es la fuente rastreada de la actividad de depuración de la Clase
14. No edites aquí los archivos. Copia `api_con_errores.py` y `hallazgos.md` a
`labs/trabajo-local/clase-14/` y trabaja únicamente sobre esas copias.

`api_con_errores.py` contiene exactamente cinco errores intencionales. La API
usa una estimación local determinista, por lo que la actividad no necesita
Databricks, credenciales, un modelo descargado ni conexión a internet.

La actividad no requiere rama, commit, push, pull request ni entrega en Canvas.
