# Starters

Archivos iniciales publicados por el profesor. No contienen la solución completa.

Salvo que una clase indique explícitamente otro flujo, no los modifiques directamente: conserva el starter como referencia y copia los archivos necesarios a `labs/trabajo-local/clase-XX/`. Esa carpeta permanece ignorada por Git, por lo que una práctica no calificable no requiere commit, push ni pull request.
