# Starters

Recursos iniciales publicados por el profesor sólo cuando una actividad los necesita. Pueden incluir datos pequeños, artefactos, fixtures, configuración no pedagógica o una estructura compleja; no contienen la solución completa.

La ruta predeterminada de una práctica es crear en `labs/trabajo-local/clase-XX/` los archivos que forman parte del aprendizaje. Si una clase usa un starter, no lo modifiques directamente: conserva el original y copia únicamente los recursos indicados a la carpeta de trabajo. Esa carpeta permanece ignorada por Git, por lo que una práctica no calificable no requiere commit, push ni pull request.
